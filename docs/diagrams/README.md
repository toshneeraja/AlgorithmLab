# Diagrams

All diagrams for this project are written as Mermaid code blocks
directly inside the markdown files, so they render automatically on
GitHub and in most markdown viewers (including VS Code with a
Mermaid extension). This folder exists to match the required project
structure, but there are no separate image files to keep here.

- System architecture diagram, component diagram, and the complexity
  analysis table: see `../architecture.md`
- Workflow (flowchart), use case diagram, and sequence diagrams:
  see `../workflow.md`

If your evaluator specifically wants exported image files (.png),
you can open `architecture.md` / `workflow.md` on GitHub (which
renders Mermaid natively), take a screenshot of each diagram, and
save it in this folder yourself.
